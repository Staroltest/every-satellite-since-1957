# 1957 以来，人类送入轨道的每一颗卫星

从 1957 年 Sputnik 1 到今天，人类送入地球轨道的每一颗卫星，都在一颗可拖动、可缩放的 3D 地球仪上，用时间轴回放天空被一点点填满的过程。

- 拖动旋转地球，滚轮 / 双指缩放
- 底部时间轴：播放 / 暂停、速度（1 / 3 / 10 / 30 年每秒）、跳到 1957 / 1961 / 1969 / 1998 ISS / 2019 Starlink / 今天
- 点击任意亮点查看该卫星：名字、NORAD 编号、发射日期、拥有者、倾角、平均高度、周期、轨道类型、状态
- 搜索框：输入 `SPUTNIK` / `ISS` / `HUBBLE` / `STARLINK` 等名字高亮匹配
- 着色切换：按状态 / 按国家 / 地区 / 按轨道高度；图例随之变化
- 每年发射数小柱状图，当前年份高亮

## 数据

来源：**CelesTrak SATCAT**（`satcat.csv`，下载于 2026-11-16）

- 原始文件：71,323 行（含火箭末级、碎片等全部编目物体）
- 本站只取 `OBJECT_TYPE = PAY`（载荷）：**28,328 颗**
- 时间范围：1957-10-04（SPUTNIK 1）至 2026-11-14
- 数据文件：`satellites.json`（约 1.97 MB，紧凑数组格式）
  - 每颗卫星：`[名字, NORAD 编号, 发射日期, 再入日期或 null, 拥有者代码, 倾角°, 平均高度 km, 周期分钟, 轨道类型]`
  - 平均高度 = (APOGEE + PERIGEE) / 2；缺失时页面按 550 km 显示
- 生成脚本：`../work/build_data.py`（读取 `../work/satcat.csv`，过滤 PAY、按发射日期 + NORAD 排序后输出）

## 本地运行

无需构建、无需 npm，直接用静态服务器打开（`fetch` 加载 `satellites.json`，`file://` 下会失败）：

```bash
cd site
python3 -m http.server 8001
# 浏览器打开 http://localhost:8001/
```

Three.js 通过 CDN import map 加载（`three@0.160.0`，jsDelivr），地球纹理同样来自 jsDelivr，加载失败时自动回退到程序化绘制的纹理。

## 诚实说明（局限）

- **位置为示意，并非实时精确位置**：每颗卫星的位置根据倾角 + 平均高度 + 由 NORAD 编号哈希得到的固定相位 / 升交点赤经生成，轨道运动按周期做匀速示意动画，没有使用实时 TLE 外推。
- 数据为 CelesTrak SATCAT 载荷清单，含已再入的卫星；累计数按发射日期统计，在轨数 = 累计发射 − 截至该日期已再入。
- 卫星数量、拥有者代码、再入日期以 SATCAT 为准；个别早期物体的高度 / 周期字段可能缺失，页面会按默认值显示并标注为“—”。
